  • One cookie, needed for the site to work: it keeps you signed in, protects forms against misuse{% if search_logging %} and holds the random visitor ID described above{% endif %}. It expires after {{ cookie_lifetime }}. We use no advertising or third-party analytics cookies and no tracking scripts.

Why we use it

  • To run the site: publish {% if self_signup %}ads{% else %}listings{% endif %}, let buyers contact {% if self_signup %}sellers{% else %}agents{% endif %}, and keep accounts secure.
  • To write ad drafts and understand searches with AI{% if search_logging %}, and to find searches that fail so we can improve them{% endif %}.
  • To show {% if self_signup %}sellers{% else %}agents{% endif %} how their {% if self_signup %}ads{% else %}listings{% endif %} perform.

  • Buyers see the {% if self_signup %}seller's{% else %}agent's{% endif %} name, and the phone number when they ask for it on a {% if self_signup %}ad{% else %}listing{% endif %} page.

How long we keep it

We keep account data while your account is open, and {% if self_signup %}ads{% else %}listings{% endif %} while they are published or needed for your records. We delete or anonymise data when it is no longer needed. You can ask us to close your account and delete your data at any time.

Your rights

You can ask to see the personal data we hold about you, have it corrected, withdraw consent, limit how we use it, or have it deleted. Email {{ privacy_email or "[contact email]" }}. We reply to access requests within 21 days. If you are not satisfied, you can complain to Malaysia's Personal Data Protection Commissioner (Jabatan Perlindungan Data Peribadi).

How we protect it

Passwords are stored hashed, the site uses encrypted connections (HTTPS), and access to the database is restricted.

Changes
